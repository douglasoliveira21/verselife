# Roadmap

1. **Foundation (current):** repository, identity, persistence schemas, container topology, login client, and headless server lifecycle.
2. **Authoritative island admission:** signed single-use entry tokens, ENet handshake, replication baseline, reconnect, and movement validation.
3. **Avatar and world persistence:** customization, spawn/teleport, island access policy, inventory domain behavior, and asset authorization.
4. **Social and communication:** friends, groups, durable chat, presence, LiveKit spatial voice, and authorized streams.
5. **Creation:** primitives, permissions, import pipeline, sandboxed Lua, and interactive HUD APIs.
6. **Commerce:** LV Coins ledger, marketplace, land sales/rental, fraud controls, and operational tooling.

Every phase requires migrations, threat review, automated tests, and executable evidence before completion.
