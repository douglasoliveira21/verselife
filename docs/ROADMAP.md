# Roadmap

1. **Foundation (current):** repository, identity, persistence schemas, container topology, login client, and headless server lifecycle.
2. **Avatar and movement (implemented):** procedural humanoid placeholder, persisted customization/equipment, camera-relative locomotion, AnimationTree, camera, seating, emotes, and runtime harnesses.
3. **Authoritative island admission:** signed single-use entry tokens, ENet handshake, replication baseline, reconnect, server-side movement validation, spawn/teleport, and island access policy.
4. **World persistence and inventory:** inventory domain behavior, asset authorization, production skinned avatar art, and expanded customization.
5. **Social and communication:** friends, groups, durable chat, presence, LiveKit spatial voice, and authorized streams.
6. **Creation:** primitives, permissions, import pipeline, sandboxed Lua, and interactive HUD APIs.
7. **Commerce:** LV Coins ledger, marketplace, land sales/rental, fraud controls, and operational tooling.

Every phase requires migrations, threat review, automated tests, and executable evidence before completion.
